## 定義と四公式の成分証明

記号 ∂x はx方向の偏微分とする。grad φ=(∂xφ,∂yφ,∂zφ)、div A=∂xAx+∂yAy+∂zAz、curl A=(∂yAz−∂zAy,∂zAx−∂xAz,∂xAy−∂yAx)。スカラーのLaplacianは ∇²φ=∂x²φ+∂y²φ+∂z²φ。ベクトルのLaplacianは各成分に適用する。

### curl grad = 0

φをC²級とする。三成分は

- ∂y∂zφ−∂z∂yφ=0
- ∂z∂xφ−∂x∂zφ=0
- ∂x∂yφ−∂y∂xφ=0

連続な二階偏導関数により各混合偏微分を交換でき、相殺する。積の微分は使わない。

### div curl = 0

AをC²級とする。定義を展開すると

∂x∂yAz−∂x∂zAy + ∂y∂zAx−∂y∂xAz + ∂z∂xAy−∂z∂yAx。

Azのxyとyx、Ayのxzとzx、Axのyzとzyを交換するとそれぞれ相殺する。積の微分は使わない。

### 積の発散

φとAをC¹級とする。各成分に積の微分を使うと

∂x(φAx)+∂y(φAy)+∂z(φAz)
=Ax∂xφ+Ay∂yφ+Az∂zφ+φ(∂xAx+∂yAy+∂zAz)
=A・grad φ+φ div A。

一階偏微分だけを使うので混合偏微分の交換は不要。

### curl curl

AをC²級とする。二重のcurlを展開した三成分は

- x成分：∂y∂xAy+∂z∂xAz−∂y²Ax−∂z²Ax
- y成分：∂z∂yAz+∂x∂yAx−∂z²Ay−∂x²Ay
- z成分：∂x∂zAx+∂y∂zAy−∂x²Az−∂y²Az

x成分では混合偏微分を交換し、∂x²Axを加えて引くと ∂x(div A)−∇²Ax。
y成分では ∂z∂yAz=∂y∂zAz、∂x∂yAx=∂y∂xAx として ∂y²Ayを加えて引くと ∂y(div A)−∇²Ay。
z成分では ∂x∂zAx=∂z∂xAx、∂y∂zAy=∂z∂yAy として ∂z²Azを加えて引くと ∂z(div A)−∇²Az。
したがって curl curl A=grad div A−∇²A。積の微分は使わない。

| 0.2 | 0.28450338785 | 0.26356227878 | 0.010470554535 |

| 方法 | 誤差比 R | 観測次数 p=log₂R |
